template<class F>
void exchange_then_sync ( F && f)

Run f, a sequence of ghost-cell exchanges, with one wait for the GPU stream at the end instead of one after each exchange. Every stream must be idle on entry, as after an MFIter loop or a BoxLocalLoops scope; the exchanges then run in order on the current stream. On CPU this just runs f.
