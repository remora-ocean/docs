The boundary records StaggeredBilinear expects for a coarse level: ext_dir at a physical edge, where a grid file supplies a ring, and int_dir across a periodic one. Build them with this rather than by hand: InterpFromCoarseLevel turns every side of a patch that doesn't reach the domain edge into int_dir before the interpolater sees it, so the interpolater's own check catches a wrong record only on patches at the edge.

One bilinear value from the four coarse values around it, at weights wx and wy measured from c00 (outside [0, 1] when extrapolating). With a period, the four are first brought within half a period of c00, and the result is then taken to the image nearest the coarse value with the largest weight, so each fine value stays on the branch of its nearest coarse point and a branch cut (the date line) falls between the same points as on the coarse level.
