Detailed Description

Bilinear coarse-to-fine interpolation of a 2D field at any horizontal staggering (rho, u, v or psi points), for grid coordinates.

The arithmetic reads the coarse field only where a grid file sets it: the domain, plus the one-cell ring outside a physical edge along a cell-centred direction. Points beyond extrapolate linearly from the two nearest values, so a coordinate linear in the index is reproduced exactly. On a NetCDF level 0 the coordinates' ghost cells beyond that ring are never set, which is why AMReX's cell and node bilinear interpolaters, which read whatever the coarse ghost cells hold, don't fit; its face interpolater is also piecewise constant across the face.

Used through InterpFromCoarseLevel with a non-periodic coarse Geometry (coordinates do not wrap; see nonperiodic_geometry) and one BCRec per component saying where the ring is: ext_dir at a physical edge, int_dir across a periodic one (see staggered_bilinear_bcrec). Across a periodic edge it reads no coarse ghost cell at all, since those hold the wrapped values from the other side. InterpFromCoarseLevel copies the parent's ghost cells into the coarse patch, so the parent needs ceil(fine ghosts / ratio) + 1 of them.

Constructed with a period (360 for a longitude in degrees, 2 pi for an angle in radians), it interpolates a field that wraps (a longitude across the date line) across the cut rather than through the jump, and keeps each fine value on its nearest coarse point's branch (see staggered_bilinear_value).
