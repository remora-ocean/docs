Detailed Description

A class to hold and interpolate time series data read from a NetCDF file.

The class only ever holds the two time steps necessary to interpoplate to the current simulation time.

void NCTimeSeriesBoundary::interp_fab ( const amrex::FArrayBox & dat_crse,
amrex::FArrayBox & dat_fine,
amrex::Orientation ori )

spatially interpolate the level-0 strip of side ori (read in) to this level's

Interpolate a level-0 boundary strip onto this level's strip.

Values are interpolated linearly along the strip between the coarse points on either side of each fine point: cell centers where the strip is cell-centered along its length, nodes where it is nodal. The point across the boundary is not interpolated.

Parameters
[in]dat_crsefab of coarse data to interpolate from
[out]dat_finefab of fine data to interpolate to
[in]orithe side the strip lies on
