9/**
10 * Scope for consecutive MFIter loops in which each box reads and writes only its own data,
11 * valid and ghost cells alike.
12 *
13 * On GPU every MFIter loop waits for its stream before it starts and for every stream it used
14 * when it ends, so that the next loop or exchange may read what any box wrote. MFIter sends
15 * all the work of one box to the same stream, where it runs in order, so loops that never read
16 * another box's data need none of that between them. Inside this scope they skip it: the scope
17 * waits for the current stream on entry and for every stream on exit.
18 *
19 * MFIter picks a box's stream from its local index, so every loop inside must iterate
20 * FabArrays with the same BoxArray (up to index type) and DistributionMapping, untiled on GPU;
21 * otherwise one box's work could land on different streams in different loops.
22 *
23 * Nothing inside may exchange ghost cells or read another box's data in any other way, read
24 * device data on the host, or free memory that a kernel on another stream may still read. A
25 * temporary FArrayBox allocated from The_Async_Arena inside a box's own MFIter iteration is
26 * safe, since it is allocated and freed in that box's stream order; a temporary MultiFab or
27 * FArrayBox made outside the loop is not, since it lives in the order of the current stream
28 * while box b runs on stream b. On CPU the scope does nothing.
29 */

32public:
